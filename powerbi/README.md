# Power BI Dashboard — Hospital Operations Analytics

## Overview

This Power BI report explores hospital operations, finance, patient flow, bed capacity, workforce, diagnostics, pharmacy and data quality using a synthetic healthcare dataset.

## Dashboard Pages

| Page | Focus |
|---|---|
| 1. Hospital Operations Overview | High-level operational KPIs |
| 2. Hospital Finance & Data Quality | Billing, payments and reconciliation issues |
| 3. Patient Flow & Admissions | Admission patterns and length of stay |
| 4. Bed & Capacity | Bed availability and occupancy |
| 5. Workforce | Employee composition and staffing |
| 6. Diagnostics | Diagnostic volumes and result status |
| 7. Pharmacy | Prescriptions and medicine stock levels |
| 8. Data Quality | Data-quality issues identified during the project |
