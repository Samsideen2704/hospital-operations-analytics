# SQL Analysis

This folder contains the SQL scripts used in the Hospital Operations & Resource Management Analytics project.

The scripts are organised by stage so the workflow is easy to follow, from checking the original data to analysing hospital operations.

## Scripts

| File | Purpose |
|---|---|
| `01_data_import.sql` | I created the 19 data tables and import the raw csv data file into each table  |
| `02_data_quality and audit.sql` | I investigate data-quality issues and validate key relationships and financial reconciliation. |
| `03_data_cleaning.sql` | I create cleaned data layers and standardise selected fields without changing the original tables. |
| `04_data_analysis.sql` | I analysed admissions, bed capacity, workforce, diagnostics, pharmacy and billing to derive meaningful insights. |
