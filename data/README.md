# Dataset Information

**Dataset:** Hospital HMIS Dataset for Healthcare Analytics  
**Author:** Shalaka Gangurde  
**Source:** [View the original dataset on Kaggle](https://www.kaggle.com/datasets/shalakagangurde/hospital-hmis-dataset-for-healthcare-analytics)

The dataset contains 19 interconnected tables covering patient admissions, hospital departments, beds, employees, diagnostics, pharmacy, insurance and billing.

The dataset is synthetic and is used for portfolio and analytical purposes.

## Data Handling

- The original CSV files were loaded into MySQL.
- Data auditing, cleaning and validation were carried out using SQL.
- The original dataset files were kept unchanged.
- The dataset files are not included in this repository. Please refer to the original [dataset source](https://www.kaggle.com/datasets/shalakagangurde/hospital-hmis-dataset-for-healthcare-analytics)
 for access.
